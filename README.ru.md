# Photo Report Generator — фотографии → презентация

[English README](README.md) · [Открыть PDF-пример](docs/synthetic-report-preview.pdf) · [PPTX-пример](<examples/reference/ExampleLocation/Sample District, Example Street 137A, pedestrian area. CI. December.pptx>)

**Задача.** Обработка множества технических фотографий и ручная сборка PowerPoint-отчётов по дням, типам работ и объектам отнимали много времени и создавали риск ошибок в оформлении.

**Решение.** Python-пайплайн считывает структуру каталогов, формирует таблицу записей, при необходимости фильтрует и подписывает изображения, собирает PPTX по заданному макету. Поддерживает пакетную генерацию и настройку параметров через конфигурацию.

**Мой вклад.** Описание требований к отчётам, организация последовательности операций, разработка с AI coding assistants, отладка, проверка итоговых файлов в реальном рабочем сценарии. Не заявляю измеренный процент ускорения.

**Быстрая проверка без рабочих фотографий.** `python -m pip install -r requirements.txt`; `python examples/tiny_demo.py`. Результат — PPTX из двух синтетических иллюстраций, а также копии входных картинок. Windows CI проверяет количество внедрённых изображений и неизменность исходников.

**Происхождение данных.** В демонстрационных отчётах могут назначаться даты/адреса и изменяться изображения. Эти материалы не подтверждают выполнение работ в указанные моменты. Пример из двух картинок тестирует компонент компоновки, а не весь многомесячный производственный процесс. Права на весь архив изображений отдельно не подтверждены.
